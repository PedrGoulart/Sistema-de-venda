Sistema de Venda
Projeto de Software — Engenharia de Software

Sistema desenvolvido como parte da disciplina **Projeto de Software**, com o objetivo de gerenciar produtos, estoque e vendas de uma loja fictícia, utilizando C# e execução via console (CMD).

Integrantes
- pedro Goulart
- Nicolas

Objetivo
desenvolver um sistema monolítico para gerenciamento de estoque e vendas, utilizando structs, listas, funções e persistência de dados em arquivos locais, sem banco de dados.

Funcionalidades previstas
- Cadastro de produtos de diferentes categorias.
- Consulta de produtos pelo nome e verificação do estoque.
- Exclusão de produtos mediante confirmação.
- Registro de vendas e atualização do estoque.
- Relatórios de vendas por categoria e total geral.
- Armazenamento e recuperação de dados por arquivos locais.
- Menus interativos no console.

Tecnologias e recursos
- Linguagem C#
- Aplicação de console (CMD)
- Structs, listas e funções
- Arquivos locais `.txt` ou `.csv`
- Git e GitHub para versionamento e disponibilização do código

Como executar
/1. Tenha o .NET SDK instalado no computador.
2. Baixe ou clone o repositório.
3. Abra o projeto em um ambiente compatível com C#.
4. Execute o sistema conforme a estrutura e as instruções do projeto.

> Observação: os comandos exatos de execução dependem dos arquivos do projeto, incluindo o arquivo `.csproj`.
